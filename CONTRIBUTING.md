# Contributing

See AGENTS.md and docs/ROADMAP.md. Open a precise question or implementation issue with scope, dependencies, acceptance checks and failure cases. Submit one reviewable change per PR. Include sources and licenses for reused material. Keep candidate generation separate from evaluation. Retain inconclusive and failed results. Report vulnerabilities privately to the repository owner rather than posting credentials or exploit-sensitive data in public issues.

Human and AI contributions are welcome. Record substantive contributions accurately; an additional model or child agent is not automatically an independent reviewer. Changes to scientific gates require both domain and implementation review before a production release. Current tests do not imply that such a release exists.
